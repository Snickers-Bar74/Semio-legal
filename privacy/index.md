# Semio Privacy Policy

_Last updated: 2026-10-24. Contact: jonathan@nullmening.org._

Semio is an independent app. It is not affiliated with or endorsed by Duolingo, Scrimba or Oracle.
"JavaScript" is used only to describe the programming language.

## Summary
Semio has no accounts or ads. Optional usage counts are off until you enable **Settings > Share usage
counts**. Crash reports are separate and are sent when crash reporting is configured in the app.
These services receive technical and connection data as described below; Semio uses the INTERNET
permission only for usage counts and crash reports.

## What is stored on your device
Your progress, streak, XP, settings, saved code drafts, notes and review schedule are stored locally on
your phone. Android may include this data in your device backup (Google Drive) or in a device-to-device
transfer, according to your phone's backup settings; Semio does not receive it.

## Optional usage counts
Usage counts help us improve the lessons. They are off by default, including for existing installations.
You can enable or disable **Share usage counts** in Settings at any time. Disabling drops queued counts,
attempts to cancel a request already in progress and stops future counts; it cannot recall data already
sent. Your choice is saved on your device, and Android backup may restore that choice. Events from
before opt-in are discarded rather than sent later. No account or lesson feature requires opting in.

With this setting enabled and analytics configured in the app, Semio counts that the app was opened; that onboarding was finished, with the answers you picked there
(why you are learning, your experience, your daily goal, whether you want a reminder and whether you
took the level check); that the level check ended, with the section it placed you in and how many
questions you got right; that a lesson, scrim or project step was finished, with the kind of lesson and
whether it was perfect; that code was run in the playground; that a streak milestone was reached; that a
quest was claimed; and that something was bought in the shop, with which item. Each count carries the
app version and the Android version. Each count carries a random number made when
the app starts; it is never stored and is forgotten when the app closes. No stable account or device identifier is sent, and no person profile is built from it. The counts go to PostHog, on servers in the EU, which
processes them on our behalf (https://posthog.com/privacy). Semio tells PostHog not to look up a
location from the connection. PostHog receives the connection's IP address when delivering a count.
Counts are kept for at most one year.

## Crash reports
When Semio crashes, it sends a crash report to Sentry, which processes it on our behalf
(https://sentry.io/privacy/). A report contains the error and where in the code it happened, the app
version, the phone model and Android version, and technical details such as memory and screen size at the
time. It contains no name, account, email address, screenshot, your code or your progress, and Semio sets
Sentry not to collect default personal data. Sentry may receive the connection's IP address to deliver the
report. Reports are kept for up to 90 days.

## Permissions
- **Notifications** (optional): daily reminders and widgets. Reminders are scheduled locally.
- **Internet**: only to send the optional usage counts and crash reports. Lessons, code and narration work offline.

## Code you run
Code you write in the Playground and in lessons runs in a sandbox on your device and is not sent anywhere.
The web preview has no network access.

## Narration
Narration is pre-recorded audio bundled with the app; when a line has no clip, Android's own text-to-speech
voice on your device reads it.

## Children
Optional usage counts are off by default for everyone, including children. The same Settings choice
and data description apply to all learners.
